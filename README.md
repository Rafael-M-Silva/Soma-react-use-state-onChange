# Soma-react-use-state-onChange

Exercício de soma em React para praticar useState e eventos onChange.

Projeto desenvolvido para fins educacionais.

## Onde está o código

Interface em `src/App.jsx`.

**Tecnologias:** `CSS`, `HTML`, `JavaScript`, `React`, `Vite`.

## Executar localmente

```bash
npm install
npm run dev
```
